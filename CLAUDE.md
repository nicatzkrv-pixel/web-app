# Project guide for Claude

## Design skills
This repo ships two design skills in `.claude/skills/`:

- **impeccable** (`/impeccable`): design workflow with sub-commands. Start a new project with `/impeccable init`; use `shape` to plan a screen before coding, `critique` / `audit` to review, and `polish` before shipping.
- **design-taste-frontend** (taste-skill): anti-generic visual direction for layout, typography, color, spacing and motion. Use it when building or redesigning pages.

For any UI work, use these skills instead of default styling. Avoid generic "AI template" looks: no default purple gradients, no centered-everything hero with three feature cards, no stock emoji icons.
