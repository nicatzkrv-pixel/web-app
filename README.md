# web-app
Radar app for payments vertical

## Claude Code setup
Design skills are committed in `.claude/skills/`, so they load automatically in Claude Code on the terminal, desktop, VS Code and claude.ai/code.

| Skill | Source | Pinned commit | License |
|---|---|---|---|
| impeccable | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | b49177d | Apache-2.0 |
| design-taste-frontend | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | 6c0b5c7 | MIT |

To update a skill, replace its folder with the latest copy from the source repo.

## Getting started
1. Open this repo in Claude Code.
2. Run `/impeccable init` to set up the design context (`PRODUCT.md`, `DESIGN.md`).
3. Describe what you want to build.
