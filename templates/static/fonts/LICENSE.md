# Fonts

Self-hosted WOFF2 subsets (latin, latin-ext) from Google Fonts, fetched with `impeccable font-fetch`.

| Family | Use | License |
|---|---|---|
| Bricolage Grotesque (variable) | display, labels, buttons | SIL Open Font License 1.1 |
| Atkinson Hyperlegible | reading text | SIL Open Font License 1.1 |
| Geist Mono (variable) | scores, counts, dates | SIL Open Font License 1.1 |

The SIL OFL 1.1 allows use, bundling and redistribution with software: https://openfontlicense.org
